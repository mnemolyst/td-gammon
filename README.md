# td-gammon
Replication of original research done at IBM on backgammon-playing AI/ML technique "temporal distance (TD) learning".\
https://en.wikipedia.org/wiki/TD-Gammon\
Requires ![Octave](https://octave.org)\
Invoke via
```
cd code
octave tdgammon.m
```
